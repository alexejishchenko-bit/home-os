# Product

## Register

product

## Users

Двое — пара. Используют на телефоне и ноутбуке в любое время дня: утренняя проверка трекеров, быстрая запись во время разговора, вечерний просмотр планов. Контекст использования — приватный, расслабленный, без стресса.

## Product Purpose

Личная операционная система для пары. Объединяет в одном месте: бытовые задачи и списки (Дом), трекинг здоровья (Здоровье), тренировки (Спорт), планирование путешествий (Путешествия). Успех — когда приложением пользуются каждый день не задумываясь, потому что оно именно под них.

## Brand Personality

Спокойное, приватное, наше. Не продукт — инструмент. Без маркетинговых приёмов, без сигналов «мы стартап». Сделано для двоих — и это чувствуется.

## Anti-references

- Todoist, Habitica, Any.do — яркая task-app эстетика, геймификация, публичность
- Карточки везде (повторяющиеся card-grid блоки)
- Градиентный текст на заголовках
- Glassmorphism как декор по умолчанию
- SaaS-стартап визуальный язык (hero-метрики, бейджи, callout-полоски)

## Design Principles

1. **Сделано для нас, не для всех.** Интерфейс может быть субъективным и конкретным — он не продаётся и не демонстрируется.
2. **Пришёл — сделал — вышел.** Каждый экран решает одну задачу. Никакой навигации ради навигации, никаких пустых состояний с призывами к действию.
3. **Цвет как система, не как украшение.** Четыре акцентных цвета несут смысл (секция). Вне этой системы цвет не добавляется.
4. **Контент — главное.** Данные и действия — это интерфейс. Chrome (шапки, бордеры, тени) — минимум.
5. **Линейность вместо иерархии.** Предпочитать плоские списки и простые таблицы вложенным карточкам.

## Accessibility & Inclusion

Личный инструмент. Минимальный порог: WCAG AA по контрасту для текста на тёмном фоне. Анимации — с `prefers-reduced-motion` альтернативой.
